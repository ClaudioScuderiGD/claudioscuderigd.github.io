# Claudio Scuderi — Game Design Portfolio

A static portfolio with project filters, shareable case-study links, gameplay footage, keyboard-accessible image viewing, and responsive navigation. No build step or dependencies are required.

- `index.html`: portfolio copy, project summaries, and original case-study evidence.
- `style.css`: responsive layout, typography, and reduced-motion support.
- `portfolio.js`: navigation, filters, media handling, image viewer, and email copying.
- `images/`, `videos/`, and `Resume.pdf`: existing portfolio assets.

Serve this directory with any static web server. Existing links such as `?page=RocketRider` continue to work. Hosting remains compatible with GitHub Pages.

The redesign follows the supplied Game Design Skills portfolio guide: clear specialization, visible individual contributions, and concrete design decisions supported by the existing project writing. No project results or metrics were invented.

Validated all ten views at 390, 768, and 1440 pixel widths, local asset references, project filters, case navigation, keyboard image viewing, and the mobile menu. External embeds and outgoing destinations require an internet connection; their remote availability was not tested.
